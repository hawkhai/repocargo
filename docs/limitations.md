# 已知限制与使用边界

以随附 EXE 的实际能力为准，不将源码基准、历史测试或模型模拟当成所有平台/场景的保证。

| 边界 | 使用建议 |
| --- | --- |
| 当前只提供 Windows x64 成品 | Linux/macOS 没有本仓库可直接运行的成品；文档提及平台逻辑不代表原生实机验收 |
| 各后端能力不同 | 完整版具备额外 Git/PDB/符号等路径；Lite 不提供同等覆盖/符号功能，CLI 不补后端能力，Fetch 不上传 |
| 非事务发布与部署 | 固定 ID 不是原子事务，不保证并发写隔离、整批回滚或失败自动恢复 |
| Python/Lite 下载失败可能先删/清空旧目标 | 重要资源先备份；不要从异常退出推断旧字节仍在 |
| 共享工作目录未隔离 | 新旧工具或不同任务使用独立工作/输出目录及扫描范围 |
| `others: ['.']` 可能扫入生成缓存 | 采用明确资源目录，排除缓存和生成文件，避免反复扩大清单 |
| 复杂资源根布局仍有历史问题 | 推荐 `mainroot: .`；绝对根、旁支根、多层根和父目录 ZIP 缓存布局先在副本上验证 |
| UNC/扩展长路径处理存在已知风险 | 不把共享库路径规范化当作完整 UNC/长路径保证，避免用未验证的 SMB 路径做重要资源发布 |
| 空/缺失上传快照与索引有不同含义 | 空 `upload.others` 优先于扫描；空快照不保证 ZIP 回退，缺失或无效索引可能报错 |
| `clean` 的核心保护有限 | 自定义主文件、被扫描进来的其他配置不一定受保护，先查索引和上传快照 |
| `copylist` 存在删除副作用 | 正常收尾可能删除复制目标；失败不承诺恢复被覆盖内容；Lite 复制不等同于完整版递归/PDB 处理 |
| Lite 的远端过期删除禁用 | 不把目录统计输出当成已删除；Python 的自动历史删除行为不同 |
| `--index-only` 不是预演 | 使用 Agent CLI 的 `--dry-run` 获取只读计划 |
| 符号、权限、软链接和环境修复有平台边界 | 不将 Windows 发行物或模拟结果解释为其他平台完整行为 |
| 密码和日志 | 显式使用自己的配置和环境变量；发布日志前另行脱敏，不依赖任意第三方输出自动脱敏 |

完整字段差异见 [使用参考](usage.md)，地址和产物规则见 [协议](protocol.md)。

若报告问题，请提供程序版本、SHA-256、退出码、脱敏后的参数及最小示例，不提交账号、真实服务地址、私钥、用户目录或完整业务配置。[贡献说明](../CONTRIBUTING.md) 提供发行仓库的维护范围。
